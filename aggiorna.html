Aggiorna Turni Operation

Da qui si aggiorna il sito dei turni con l'ultima versione del file Excel. Il file resta sul tuo computer: viene letto dal browser e sul sito arrivano solo i turni cifrati.

1Password di caricamento

Password di caricamento errata. Controlla maiuscole e trattini.

2File Excel dei turni

Esempi: SINGH (sempre) · CALEFFI dal 01/10/2026 · CALEFFI dal 01/10/2026 al 28/02/2027

3Controlla e pubblica

  1. Apri github.com/micheleongaro/turnazioni → Upload files (accedi con il tuo account GitHub).
  2. Trascina il file index.html appena scaricato e premi Commit changes. Sostituisce quello vecchio.
  3. Dopo 1–2 minuti il sito è aggiornato. Su telefono, se vedi ancora i dati vecchi, ricarica la pagina.

Il foglio letto è “Dati” (tabella Turni). Se il file è stato appena modificato, aprilo in Excel e salvalo prima di caricarlo qui, così le formule hanno i valori aggiornati.
